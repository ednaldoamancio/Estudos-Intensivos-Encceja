🧠 Mapa Mental: Interpretação de Dados

Dados Contam Histórias
Gráfico de Barras:
Compara quantidades. A barra maior = maior valor. Fácil de ler: é só olhar a altura.
Gráfico de Pizza:
Mostra partes de um todo (100%). A fatia maior = maior porcentagem. Pense num bolo dividido.
Tabela:
Organiza dados em linhas e colunas. Cruze a linha com a coluna pra achar o valor. É tipo uma planilha.

Papo Reto: Resumo da Matéria

Ler gráficos e tabelas é uma habilidade que vale ouro na prova. A boa notícia: não precisa de fórmula complicada. É interpretação pura.

No gráfico de barras, cada barra representa uma categoria. A barra mais alta = maior valor. No gráfico de pizza, o círculo inteiro é 100%. Cada fatia é uma porcentagem. No gráfico de linhas, a linha subindo = crescimento, descendo = queda.

Nas tabelas, a chave é cruzar linhas e colunas. Exemplo:

MêsVendas (R$)Lucro (R$)
Janeiro5.0001.200
Fevereiro7.0002.100
Março4.500900

Se a prova perguntar "Em qual mês o lucro foi maior?", é só olhar a coluna "Lucro" e achar o maior número: Fevereiro (R$ 2.100). Também pode pedir a média: some tudo e divida pela quantidade. Média de vendas = (5.000 + 7.000 + 4.500) / 3 = R$ 5.500.

3. A média aritmética é muito cobrada na prova. Se suas notas em 4 provas foram: 6, 8, 7 e 9, qual é a sua média?
