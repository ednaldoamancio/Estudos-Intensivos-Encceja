🧠 Mapa Mental: Geometria Básica

Medir Formas = Pontos na Prova
Perímetro:
É a "cerca" ao redor da forma. Some todos os lados. Ex: quadrado de lado 5 → P = 5+5+5+5 = 20.
Área:
É o "piso" que cabe dentro da forma. Retângulo: base x altura. Triângulo: (base x altura) / 2.
Volume:
É o "espaço interno" de uma caixa. Cubo/paralelepípedo: comprimento x largura x altura.

Papo Reto: Resumo da Matéria

Geometria é sobre medir coisas do mundo real. Imagina que você vai cercar um terreno: precisa saber o perímetro (a volta toda). Vai colocar piso no chão: precisa saber a área (o espaço interno). Vai encher uma caixa d'água: precisa saber o volume (quanto cabe dentro).

Retângulo: Perímetro = 2 x (base + altura) | Área = base x altura
Triângulo: Área = (base x altura) / 2
Caixa (Paralelepípedo): Volume = comprimento x largura x altura

Dica matadora: a prova sempre traz problemas do dia a dia. "Quanto de tinta pra pintar uma parede?" = área. "Quanto de cerca pra fechar o quintal?" = perímetro. "Quantos litros cabem na piscina?" = volume. Identifique o que a questão pede e aplique a fórmula certa!
